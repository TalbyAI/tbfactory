## Question

Can a developer contribute one local TypeScript Factory Plugin and a User compose
its capabilities through a small declarative authoring surface without adding code?

Contribute a step type, a classification expression, and an inbound/outbound fake
integration. Show capability discovery, configuration validation, a reusable
Workflow and Trigger, and the distinction between install authority and configure
permissions. Exercise incompatible/missing plugin versions and unauthorized
configuration. A minimal form or configuration preview is sufficient; a full visual
editor and package marketplace are outside scope.

Link the self-contained prototype and have the User judge vocabulary, effort,
error messages, and whether both extension levels deliver the intended product.
